## What Azora Does

Azora Development is a small software and game-development studio focused on building tools that solve real problems for online communities, Minecraft servers, developers, and creators.

Our work mainly centers around:

* **Minecraft Mods & Mod Suites** - gameplay utilities, server tools, team systems, claims, essentials, and quality-of-life mods.
* **Discord Bots & Community Systems** - automation, moderation support, analytics, internal tools, and server infrastructure.
* **Web Apps & Dashboards** - modern websites, admin panels, analytics dashboards, and SaaS-style tools.
* **Backend & Infrastructure Tools** - APIs, databases, workers, deployment systems, and scalable services.
* **AI-Assisted Systems** - practical AI integrations for planning, automation, summaries, and internal workflows.

## Current Focus

Azora’s current goal is to build a strong ecosystem of useful software across a few connected areas:

### Minecraft Development

We build Minecraft mods and systems designed for both players and server owners.
This includes standalone mods, shared libraries, server utilities, and larger connected mod suites.

Examples of project areas include:

* Essentials-style server tools
* Team and claim systems
* Gameplay utilities
* Quality-of-life mods
* NeoForge / Forge mod development
* Shared libraries and reusable systems

### Discord & Community Infrastructure

We create tools that help Discord communities operate better, understand activity, and manage growth.

This includes:

* Discord bots
* Server analytics
* Moderation and automation tools
* Internal staff systems
* Community dashboards
* Long-term data tracking

### Web, Analytics, and SaaS Tools

Azora also works on web-based tools and dashboards for managing communities, projects, and software systems.

This includes projects like:

* **Prism Analytics** - a Discord analytics platform built to give communities better insights into growth, activity, engagement, and server health.
* Project dashboards
* Admin panels
* Public websites
* API-driven tools
* Internal management systems

## Philosophy

Azora is built around a few simple ideas:

* Build things that are **actually useful**
* Focus on **real-world problems**, not just demo projects
* Keep systems **clean, modular, and scalable**
* Make tools that can grow from small communities to larger platforms
* Prioritize **performance, maintainability, and usability**
* Open-source when it makes sense, keep things controlled when needed
